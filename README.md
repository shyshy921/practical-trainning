# JavaRTS - 星际殖民者

星际殖民者（Interstellar Colonizer）是本组基于 JavaFX 开发的资源管理策略游戏：玩家建造并经营一座不断扩张的殖民地，在平衡资源与人口的同时推进科技、应对随机事件。

当前版本已实现：科技树（11 个科技节点、4 级前置依赖，研究「星际航行」即触发胜利）、随机事件系统（每 5~14 个游戏日触发一次，15 种事件，各含多选项分支）、JSON 存档读档、建筑 1~5 级升级、居民疲劳系统、饥饿 Debuff、猎人工会（按交付猎物结算食物）、资源历史折线图。

The course focused on design patterns, so the primary emphasis is on the code structure and application of patterns rather than graphical quality or gameplay optimization.

## Prerequisites if you want to compile the source code

- Java 21
- Apache Maven if you want to compile with maven
- JavaFX

## How to play

要启动游戏，请进入JavaRTS文件夹并输入“mvn javafx:run”或使用我们的版本。
在游戏开始时，玩家拥有资源去建造一些能够维持数天的建筑和食物。
这些资源显示在屏幕的顶部。在屏幕底部，有两个按钮对应两个选项卡：

- Buildings Tab:
  - 显示您可以建造的建筑物，以及有关其居民，工人，每日资源生产和消费的信息。
  将鼠标悬停在建筑卡片上显示其建造成本。
  点击一个建筑来选择它，然后把它放在地图上。
  透明卡片代表你目前缺乏资源去建造的建筑。

- People Management Tab:
  - 显示你放置的建筑物及其状态。
  显示总人口和工人数量。
  允许通过分配居民，移除工人等来管理建筑物。
  错误将出现在屏幕顶部（例如，试图将工人分配到不合适的建筑物）。
游戏地图在屏幕中央。根据您的窗口大小，地图可能在瓷砖之间有间隙。要放置建筑，从**Buildings Tab**中选择一个，然后点击一个贴图。如果资源不足，则返回错误提示。你也可以点击地图上的建筑，打开一个详细的管理窗口，在那里你可以查看它的状态，修改工人或居民，如果需要的话可以删除它。
### Important Tips

确保人口有足够的食物（每人每天1单位）以防止死亡。
这可能导致建筑物空置或人手不足，造成资源短缺。
只有在配备充足人员的情况下，才能实现建筑物的显示生产/消费。
部分人员配备导致产出成比例。在正常的消耗成本下，在5天内提升一座建筑的产量会翻倍，但会使用1个工具并增加崩溃风险。
资源的过度消耗会阻塞建筑，使生产停止。
在重新启动操作之前解决短缺问题。
如果需要，你可以手动停止建筑的生产。
早期游戏策略：优先考虑食物和木材生产，其次是生产建筑或消费所需材料的建筑。
随着游戏的发展以及建筑和居民数量的增加，游戏可能会因为我们没有专注于优化而放慢速度。

## 运行方式

```bash
cd JavaRTS
./mvnw javafx:run
```

需 JDK 21（`pom.xml` 中 `maven-compiler-plugin` 的 `release` 为 21）。
